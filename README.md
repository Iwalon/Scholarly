# Scholarly

A minimalist academic companion app featuring a refined open-book interface and elegant design. Scholarly helps users organize, reflect, and study with clarity and focus.

![Scholarly Logo](link-to-your-logo-image)

## ✨ Features

- 📖 Clean, distraction-free interface  
- 📝 Ruled cream pages for notes and reflections  
- 📚 Elegant academic aesthetic with gold accents  
- 🔖 Pine green bookmark for quick access  
- 🌟 Gold star medallion for premium feel
